      🏫 우리 학교 온라인 시간표 시스템 사용 설명서

      1️⃣ 마스터 (최고 관리자) 이용 방법

      • 마스터 로그인: 숨겨진 주소(/master)로 접속하여 마스터 전용 아이디와 비밀번호로 로그인합니다.
      • 학교 승인 및 관리: 신규 가입을 신청한 학교들의 목록을 확인하고 [승인] 또는 [비활성화/삭제] 처리를 할 수 있습니다.
      • 학교 코드 및 정보 수정: 시스템에 가입한 학교들에게는 1, 2 등의 자연수 학교 코드가 부여됩니다. 마스터 대시보드에서 각 학교의 학교 코드나 관리자 아이디/비밀번호를 언제든지 임의로 수정할 수 있습니다.

      2️⃣ 학교 관리자 (시간표 담당 선생님) 이용 방법

      • 학교 가입 신청: 메인 웹사이트의 [학교 등록 신청] 버튼을 눌러 우리 학교 이름과 관리자 계정을 생성하고 마스터의 승인을 기다립니다.
      • 기초 환경 설정: 마스터 승인 완료 후 로그인하여, 상단 [학교/교사 설정] 메뉴에서 우리 학교에 맞는 '학년/반'과 '담당 교사' 목록을 세팅합니다.
      • 1교사 다교과 등록: 한 선생님이 여러 과목을 담당하시는 경우, 각 과목마다 선생님을 따로 등록하시면 됩니다. 단, 교사 이름과 사용하실 아이디(로그인 ID)를 반드시 동일하게 등록해주세요. 이렇게 하면 선생님이 로그인 시 하나의 계정으로 담당하시는 모든 과목의 시간표를 통합해서 볼 수 있습니다.
      • 가입 승인 처리: 교사나 학생들이 가입 신청을 하면 대시보드에 목록이 뜹니다. 소속을 확인한 후 [승인]을 해주어야 그들이 사이트를 이용할 수 있습니다.
      • 시간표 생성 및 강제 적용: 시간표 생성 탭에서 시간표를 작성할 때, 선생님 일정이 중복되면 경고 메시지가 나타납니다. 예외적인 상황이라면 [무시하고 적용] 버튼을 눌러 강제로 배정할 수도 있습니다. 완성된 시간표는 학기별 시간표와 일일 시간표에 자동으로 모두 적용됩니다.
      • 일자별 시간표 즉각 조회: 일자별 시간표 메뉴에서 달력으로 날짜를 선택하거나, 드롭다운으로 학년/반을 변경하면 지연 없이 시간표가 즉시 화면에 나타납니다.

      3️⃣ 교사 이용 방법

      • 회원가입: 메인 웹사이트에서 [교사 가입]을 누르고, 학교 관리자가 알려준 우리 학교의 [학교 코드 번호]와 자신의 담당 과목 등을 입력하여 가입합니다. 여러 과목을 담당하시는 경우 과목별로 가입을 진행하되, 이름과 아이디를 똑같이 입력하시면 시스템이 자동으로 계정을 하나로 통합해 드립니다.
      • 시간표 조회: 학교 관리자가 가입을 승인한 뒤 로그인하면, [교사 시간표] 탭에서 여러 과목을 가르치시더라도 자신의 아이디 하나로 모든 담당 과목의 시간표를 한눈에 볼 수 있습니다.

      4️⃣ 학생 이용 방법

      • 회원가입: 메인 화면에서 [학생 가입]을 누르고, [학교 코드 번호]와 자신의 학년, 반, 이름을 정확히 입력하여 가입을 신청합니다.
      • 시간표 조회: 가입이 승인된 후 로그인하면, 번거롭게 학년 반을 찾을 필요 없이 내 학년/반에 맞는 시간표가 맞춤형으로 화면에 즉시 표시됩니다.
